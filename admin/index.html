Cada cliente é uma pasta própria: dentro dela você cadastra os relatórios de fechamento (dashboards de apresentação) daquele cliente, mês a mês. Só quem faz login aqui consegue ver — não aparecem no site público.

Além do seu login (administrador), você pode criar outros acessos com permissão limitada: um usuário do tipo Cliente só enxerga a pasta de um cliente específico (em modo leitura); um usuário do tipo Dashboard só enxerga um relatório específico — útil pra compartilhar um link de acesso com o próprio cliente, sem dar acesso ao painel inteiro.
