Como gerar meu token de acesso?
  1. Acesse github.com → foto do perfil → Settings
  2. No menu lateral, vá em Developer settings → Personal access tokens → Fine-grained tokens
  3. Clique em Generate new token
  4. Em "Repository access", escolha Only select repositories e selecione este repositório (mognon)
  5. Em "Permissions → Repository permissions", defina Contents: Read and write
  6. Gere o token e cole aqui em cima — ele fica salvo só neste navegador, nunca é enviado para mais ninguém além do GitHub
